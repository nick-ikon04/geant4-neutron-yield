# TALYS data provenance

This directory contains a minimal subset of neutron-induced reaction tables generated with TALYS 2.0 on 2025-11-03. It retains only the target header (`all.tot`) and files needed by the configured `(n,γ)`, `(n,2n)`, `(n,3n)`, `(n,p)`, `(n,α)` and, for ²⁴¹Am, fission channels.

The files were selected from the related project archive to make the parsing and folding examples runnable without publishing tens of megabytes of intermediate TALYS output. They are generated numerical data and are not independently validated here. Consult the TALYS distribution terms and cite TALYS when using them in research.
