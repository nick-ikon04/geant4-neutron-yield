# Дослідження виходу нейтронів у Geant4

[English version](README.md)

Відтворюване дослідження виходу нейтронів із циліндричних мішеней із природного урану та вольфраму під дією електронних і протонних пучків. Скрипти Python автоматизують серії розрахунків, збирають результати Монте-Карло, будують графіки та поєднують спектри нейтронів із перерізами TALYS для дослідницької оцінки трансмутації.

> Стан роботи: код упорядковано й перевірено перед публікацією. Додані графіки взято з пізнішого успішного запуску, а не з попередньої помилкової серії з однаковими значеннями для U та W. Ці результати отримано до виправлення підрахунку перетинів межі, тому вони є довідковими, а не валідованими еталонними даними. Перед науковим цитуванням їх слід перерахувати.

## Що містить репозиторій

- застосунок Geant4 на C++17 із налаштуванням пучка, енергії, матеріалу та геометрії;
- послідовний режим запуску без конфліктів лічильників і вихідних файлів;
- автоматичне сканування параметрів для електронів і протонів;
- таблиці виходу, статистичні похибки та графіки;
- дослідницький конвеєр трансмутації для ¹²⁹I, ¹³⁵Cs і ²⁴¹Am;
- мінімальний набір згенерованих таблиць TALYS 2.0;
- документацію українською та англійською, тести й перевірки Python у CI.

## Довідкові результати успішного запуску

Для всіх наведених точок радіус мішені дорівнює 20 мм, використано 10 000 первинних частинок, а `L` означає **півдовжину** мішені Geant4 (повна довжина циліндра — `2L`). Похибка — збережена пуассонівська оцінка.

|---|---:|---:|---:|---:|
| електрони | 200 МеВ | природний U | 100 мм | 0,0831 ± 0,0029 |
| електрони | 200 МеВ | W | 100 мм | 0,0451 ± 0,0021 |
| протони | 800 МеВ | природний U | 100 мм | 28,4551 ± 0,0533 |

Успішна серія показує значне зростання виходу зі збільшенням енергії протонів і загалом більший вихід для природного урану, ніж для вольфраму. Значення залишаються попередніми: архівна версія рахувала лише вихід через бічну оболонку, а поточний код рахує перший вихід через будь-яку поверхню мішені.

## Збирання та запуск

Потрібні CMake 3.16+, компілятор C++17, Geant4 із компонентами UI/візуалізації/аналізу та Python 3.10+.

```bash
cmake -S . -B build
cmake --build build -j
python -m pip install -r requirements.txt
./build/neutron_yield macros/electron_200_U.mac
```

Перегляд запланованої серії без запуску Geant4:

```bash
python run_scan.py --dry-run --beam electron --material U
```

Повний розрахунок виходу:

```bash
python run_scan.py --executable build/neutron_yield --out results --nprimary 10000
python analysis/analyze_yield.py --in results --out out
```

Також можна використати `./run_full_pipeline.sh`. Для етапу трансмутації потрібні спектри Geant4, на які посилаються файли `analysis/configs`.

## Важливі зауваження

- `L_mm` — півдовжина, хоча у старих назвах файлів вжито слово “thickness”.
- Кожен нейтронний трек реєструється один раз — під час першого виходу з мішені.
- Застосунок навмисно працює послідовно: початкові лічильники та спільні імена файлів були небезпечними в багатопотоковому режимі.
- Періоди напіврозпаду продуктів у JSON-файлах — сценарні вхідні значення з робочої версії. Перед науковим або інженерним використанням їх треба звірити з оціненими ядерними даними.
- Модель призначена для досліджень і навчання, а не для рішень із радіаційної безпеки, захисту, медицини чи регуляторної відповідності.

Докладний перелік виправлень і обмежень наведено в [`docs/CODE_AUDIT.md`](docs/CODE_AUDIT.md).
